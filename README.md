Kebabų Namai — Local Restaurant Landing Page
A simple, fast, and responsive front-end website built for a local kebab restaurant in Šiauliai, Lithuania. Designed with a dark UI theme to match the restaurant's vibe, featuring dynamic menu filtering, bilingual support (LT/EN), and a mobile-friendly layout.

Features
Dynamic Category Filter: Seamlessly switch between Kebabs, Snacks, and Drinks without refreshing the page.

Bilingual Interface: Instant language switching between Lithuanian and English using pure HTML data-* attributes and JS.

Responsive Navigation: Clean mobile drawer menu built for small screens and touch interactions.

Custom CSS Architecture: Standard CSS variables for color themes, smooth scrolling, and reduced-motion support.

Tech Stack
HTML5 — Semantic markup, accessibility features (aria-*), and video embedding.

CSS3 — Custom properties, CSS Grid, Flexbox, media queries, and dynamic blur effects (backdrop-filter).

Vanilla JavaScript — DOM manipulation for menu filtering, language toggling, and mobile navigation.

FontAwesome & Google Fonts — Icons and typography.
